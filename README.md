# 🐱 PaperDex — 논문 도감

매일 읽은 논문 + GPT 대화 + 요약 + 직관적 설명을 아카이빙하는 픽셀 테마 로컬 웹앱.

## 실행

```bash
python3 ~/paperdex/server.py          # http://127.0.0.1:8765 자동으로 열림
python3 ~/paperdex/server.py --no-open --port 9000
```

설치할 패키지 없음 (Python 표준 라이브러리만 사용). 폰트·마크다운·수식 렌더러는 CDN에서 불러옴.

## 기능

- **홈**: 오늘 읽은 논문, 🔥 연속 기록(스트릭), 깃헙 스타일 논문 잔디, 최근 7일, 배지
- **스크린샷**: 논문 figure를 캡처해서 ⌘V로 붙여넣거나 끌어다 놓기 (자동 압축, 캡션, 크게 보기)
- **기록**: arXiv 링크 → 제목/저자/초록 자동 입력, GPT 대화 붙여넣기 → 말풍선으로 표시 (`You said / ChatGPT said`, `나의 말 / ChatGPT의 말` 인식), 작성 중 자동 임시저장
- **한 번에 채우기**: "정리 프롬프트"를 GPT에 보내고 답변을 붙여넣으면 요약/직관/아이디어/의문점/태그 자동 입력
- **클러스터**: 마인드맵(클러스터/태그 기준), TF-IDF + k-means로 비슷한 주제끼리 묶기, 2D 논문 지도, 논문별 "비슷한 논문"
- **아이디어 랩**: 논문 조합 가챠, 아이디어 노트(씨앗→새싹→나무), 씨앗 보드(논문별 핵심 아이디어/의문점 한 줄씩), GPT 브레인스토밍 프롬프트 빌더
- 수식(KaTeX), 마크다운 렌더링, 전체 검색, JSON 내보내기/가져오기

## 데이터

- `data/db.json` — 모든 논문/아이디어
- `data/backups/db-YYYY-MM-DD.json` — 그날 처음 저장할 때 자동 백업
- `data/images/` — 스크린샷 (로컬 모드)
